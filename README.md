Deep learning-based satellite image classification using MobileNetV2 transfer learning to classify images into Cloudy, Desert, Green Area, and Water categories.

Project Overview

Satellite images contain different geographical features such as vegetation, water bodies, deserts, and cloud-covered regions. This project develops an image classification model that automatically identifies the category of a given satellite image.

The model uses MobileNetV2 pretrained on ImageNet as a feature extractor, with a custom classification head trained specifically for the four satellite-image classes.

Classes

The model classifies images into:

Cloudy
Desert
Green Area
Water
